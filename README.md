# Agoranome inspector

The public inspector of the x402 market: it measures every paid endpoint with real demand, publishes who asks
the listed price and pays the listed address, and proves each figure in an open book that anyone can check.

Agoranome: fair markets for machines. We build the tools that help AI agents find, judge and trust the services
they pay for, and we pledge 15% of what we earn to a public cause.

The code arrives by pull request.
